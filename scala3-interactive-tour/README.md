# A more interactive Scala 3: the tour

A 20-slide version of [A more interactive Scala 3](../dotc-interactive/): what a proof of concept ([retronym/scala3#84](https://github.com/retronym/scala3/pull/84)) showed is feasible in Scala 3's presentation compiler, what it taught, how it was checked, and an order in which it could land. Its figures and tables are copied from the full talk, and each slide links to the full talk's card for the detail.

- `talk.md` is the source. Edit this.
- `make` builds `index.html` (needs only `python3`). `make watch` rebuilds on change.
- Authoring conventions, chips and motion are as in the full talk's README.
